Ожидает в контексте order_items из pdf_service._order_items_context: регулярные поля прибора и extra — дополнительные поля из снимка схемы, уже с подставленными прочерками. Таблица на каждый прибор своя, заголовок «Прибор N из M» — первая строка этой же таблицы. repeat="1" — атрибут xhtml2pdf, он же repeatRows у reportlab: CSS page-break-inside библиотека не читает вовсе (таблицы всегда splitByRow), а repeatRows даёт две нужные гарантии. Одна: reportlab не делит таблицу так, чтобы на странице осталась только шапка, — заголовок не оторвётся от полей. Вторая: если набор полей всё-таки не влез, заголовок повторяется сверху продолжения, и на второй странице видно, чей это прибор. {% endcomment %} {% for item in order_items %} 1 %} repeat="1"{% endif %}> {% if order_items|length > 1 %} Прибор {{ forloop.counter }} из {{ order_items|length }} {% endif %} Тип прибора:{{ item.device_type }} Модель:{{ item.model }} Серийный номер:{{ item.serial_number }} Количество:{{ item.quantity }} {% for field in item.extra %} {{ field.label }}:{{ field.value|linebreaksbr }} {% endfor %} {% endfor %}
